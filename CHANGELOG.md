# Changelog | سجل التغييرات

<div dir="rtl">

سياسة إلزامية: **كل إصلاح أو ترقية يغيّر رقم النسخة.** الحارس الآلي في CI يرفض أي وسم إصدار لا يطابق `versionName` في `app/build.gradle.kts`، فلا يمكن نشر إصدار دون رفع الرقم.

</div>

**Mandatory policy: every fix or upgrade MUST change the version number.** The CI guard rejects any release tag that does not match `versionName` in `app/build.gradle.kts` — no release can be published without a version bump.

## Versioning rules | قواعد الإصدار

| Change type / نوع التغيير | Version bump / رفع النسخة | Example / مثال |
|---|---|---|
| Bug fix / إصلاح خلل | Patch: `v1.0.x` | v1.0.1 → v1.0.2 |
| New feature, mode, theme / ميزة أو نمط أو موضوع جديد | Minor: `v1.x.0` | v1.0.1 → v1.1.0 |
| Breaking change / تغيير جوهري | Major: `v(x+1).0.0` | v1.0.1 → v2.0.0 |
| Docs only / توثيق فقط بلا كود | No release / بلا إصدار | — |

<div dir="rtl">

قواعد ملزمة:

- `versionCode` يزيد 1 وحدة مع **كل** إصدار منشور (شرط أندرويد: تصاعدي دائماً).
- مسار الإصدار: ارفع `versionCode` و`versionName` → أضف سطراً في هذا السجل → التزم → `git tag vX.Y.Z && git push origin vX.Y.Z` → CI يشغّل الاختبارات ويبني وينشر الإصدار مع APK تلقائياً.
- حارس CI: وسم لا يطابق `versionName` يُفشل البناء برسالة خطأ صريحة.
- التغيير التوثيقي الصرف (بلا كود) لا يرفع النسخة ولا يصدر إصداراً جديداً.

</div>

- Release flow: bump `versionCode` + `versionName` → add a CHANGELOG entry → commit → `git tag vX.Y.Z && git push origin vX.Y.Z` → CI runs tests, builds, and publishes the release with the APK automatically.
- CI guard: a tag not matching `versionName` fails the build with a clear error.

## [1.6.1] — 2026-10-26

### Fixed | إصلاحات
- **توقيع إصدار ثابت — stable release signing** (directive: «حافظ على نفس التوقيع release»). قبل هذا الإصدار كان كل إصدار يُوقَّع بمفتاح مؤقت يُولَّد من جديد (محلياً بعد كل إعادة ضبط للبيئة، وفي CI مع كل وسم)، فكان هاتف أندرويد يرفض تثبيت تحديث فوق نسخة مثبتة (تعارض التوقيع) ويتطلب إزالة التثبيت — وبها تُفقد بيانات اللعب.
- **مخزن مفاتيح دائم واحد** (`tng-release.keystore`, RSA-2048, صلاحية 30 سنة، بصمة SHA-256 `d335a7ab…02f0c6`) أصبح الآن مصدر التوقيع الرسمي في المسارين معاً:
  - **CI**: يُسترجَع من GitHub Actions Secrets (`TNG_KEYSTORE_B64` + كلمات المرور) على كل وسم إصدار — بلا أسرار يعود للسلوك المؤقت القديم مع تحذير صريح.
  - **محلياً**: نفس الآلية القائمة عبر متغيرات البيئة `TNG_KEYSTORE`/`TNG_KEYSTORE_PASSWORD`/`TNG_KEY_ALIAS`/`TNG_KEY_PASSWORD` (موثَّقة في `docs/SIGNING.md`).
- **بوابة توقيع في CI**: بعد بناء APK الإصدار تُفحص بصمة الشهادة آلياً — إن لم تطابق المفتاح الدائم **فشل الإصدار** بخطأ صريح، فلا يمكن أن يخرج إصدار بتوقيع مختلف مجدداً.

### Upgrade note | ملاحظة الترقية
- بسبب اختلاف توقيعات الإصدارات السابقة (كلها مفاتيح مؤقتة ضاعت)، فإن التثبيت فوق نسخة قديمة يتطلب **إزالة تثبيت واحدة أخيرة** ثم تثبيت v1.6.1. من هذا الإصدار فصاعداً كل التحديثات القادمة تُثبَّت مباشرة فوق بعضها **دون إزالة ودون فقدان التقدم** — هذا هو الغرض من التوقيع الثابت.

### Docs | توثيق
- `docs/SIGNING.md`: سياسة التوقيع الكاملة (مواضع المخزن، الأسرار، آلية الاسترجاع في CI، بوابة البصمة، تعليمات النسخ الاحتياطي للمالك، ومراجعة v1.6.0 وأسباب ضياع مفتاحها).

## [1.6.0] — 2026-10-26

### Added | إضافات
- **«الغلاف الصوتي الكامل» — the full audio shell release** (approved roadmap: the audio track A1–A7 + V5 + one UX item, per `docs/DEV_PLAN_V1.6.0.md`, all anchored to a fresh code audit).
- **A1 — Audio focus**: the running round now owns game audio focus (USAGE_GAME). A phone call or another media app pauses our music instantly; a permanent loss auto-pauses and saves the round; focus regained resumes the music. The decision table (`FocusPolicy`) is pure and unit-tested; `AudioFocusHelper` is the thin Android half (AudioFocusRequest on O+, legacy path for minSdk 24).
- **A2 — Combo pitch ramp**: the combo sample (present in the files since v1.0 but never played) finally fires from combo 2 upward, re-pitched +0.05 per chain link up to 1.5× (`ComboPitch`, SoundPool rate). A long chain is *heard* climbing.
- **A3 — Dynamic danger music**: one routing table (`MusicRouter`) now decides the track for the whole round — zen stays calm, an endangered stack jumps straight to the intense track regardless of level, and the classic level-8 ramp is preserved. The track switches only when the routed result actually changes (no thrash).
- **A4 — Music ducking under the announcer**: big moments (tetris, perfect clear, records, round end) lower the music to 45% for 1.1 s so the voice carries (`DuckPolicy` + `MusicEngine.setDucked`); re-entry extends the window instead of stacking timers.
- **A5 — Dedicated PERFECT & B2B stings**: a perfect clear no longer borrows the plain clear sound, and back-to-back gets its own bonus blip layered over the tier sound. Eight new WAVs (4 synthesized packs × 2), same v1.3.0 v2 engineering (sub layer + sweep + noise transient), generated by the committed `scripts/gen_audio_v16.py`. The T99 pack keeps its real-recordings-only character and falls back through the tested chain (PERFECT→TETRIS→CLEAR, B2B→COMBO→CLEAR).
- **A6 — Complete background silence**: leaving the app mid-round now stops the announcer instantly (no stray "pause" line playing in your pocket) along with the music, and keeps the session saved.
- **A7 — Audible sound-pack preview**: every sound-pack card in the store has a «معاينة الصوت» button playing a two-sting demo (clear, then tetris) straight from that pack without switching the active one. Honest limit: SoundPool loads asynchronously, so the very first tap on a never-loaded pack can arrive silent — the second tap always sounds.
- **V5 — Audio-visual sync**: the HUD combo chip scales with the *same* pitch ramp that drives the sound (`FxMath.comboChipScale`, one source of truth), and the big-moment flashes now respect the effects-intensity setting (they were fixed values that ignored V8).
- **U1 — Richer round summary**: the summary finally shows the best combo and Tetrises count — data the engine always tracked.

- **15 new unit tests** (combo pitch null/base/monotonic/cap, music routing zen/danger/level/determinism, duck policy, focus decision table, combo-chip scale bounds, PERFECT/B2B suffixes and fallback chains): **18 suites / 136 tests** total.

- `versionCode` 7 → 8, `versionName` 1.5.0 → 1.6.0.

## [1.5.0] — 2026-10-26

- **V3 — Hard-drop trail & impact dust**: a fading column-wide trail along the swept path (200 ms, piece colour) plus a 6–10 particle dust puff at the landing cells, both fully disabled under reduced motion.
- **V4 — Visual danger pulse**: while the audio DangerTracker is inside its 15/13 hysteresis window, the board edge and the last free row glow red, scaling with proximity to the top. - **V6 — Themed board frame**: the asset-pack frame is used for *every* theme (not only T99), tinted per theme so each theme stamps the board border; the Hold container glows with the theme accent while the swap is available, dims to a muted gray once consumed, and the first Next slot glows.

## [1.2.0] — 2026-10-26

### Changed | تغييرات
- **Touch gestures v2 — full-screen and impossible to miss** (based on real-device feedback that the board-only gestures felt weak):
  - Gesture surface expanded from the board box to the **entire play screen**; buttons, HUD and dialogs keep hit-testing priority so nothing breaks.
