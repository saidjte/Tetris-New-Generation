## 1) نتائج التدقيق — الفجوات المؤكدة

| # | الفجوة | الدليل في الكود |
|---|---|---|
| W1 | **لا يوجد أي طلب «تركيز صوتي» (Audio Focus)** — مشغل الموسيقى الخارجي (Spotify…) واللعبة يصدران صوتاً معاً | `grep AudioFocus` = صفر نتائج في كل المصدر |
| W2 | **صوت الكومبو موجود في الملفات (4 حزم) لكنه لا يُشغَّل أبداً** — والسلاسل لا ترتفع نغمتها | `grep "Sound.COMBO"` = خريطة الاحتياط فقط؛ `SfxEngine.play` يثبّت `rate = 1f` |
| W3 | **لا موسيقى خطر ديناميكية** — الموسيقى المكثفة ترتبط بالمستوى 8 فقط بينما يتتبع المعلق الخطر أصلاً عبر DangerTracker | `GameViewModel`: `intenseMusicOn` عند `level >= 8` فقط |
| W4 | **لا خفوت للموسيقى تحت المعلق** — اللحظات الكبرى (تتريس/مثالية/رقم قياسي) تُسمع فوق موسيقى بكامل صوتها | `MusicEngine` لا يملك أي ducking؛ `VoiceEngine` مستقل |
| W5 | **المثالية الكاملة تشغّل صوت CLEAR العادي**، وB2B بلا صوت خاص إطلاقاً | `handleEvents`: `event.perfectClear -> sfx.play(CLEAR)`؛ لا B2B في `SfxEngine.Sound` |
| W6 | **صوت المعلق يستمر في الخلفية** عند تصغير التطبيق | `GameScreen` ON_PAUSE ⇒ `pauseRound` يشغّل صوت PAUSE ثم يوقف الموسيقى فقط |
| W7 | **لا معاينة صوتية في المتجر** — اللاعب يشتري حزمة أصوات (150 عملة لـ T99) دون أن يسمعها | `StorePreview` مرئي فقط؛ لا مسار صوتي في `StoreScreen` |
| W8 | **وميض اللحظات الكبرى يتجاهل إعداد شدة المؤثرات (V8)** — قيم ثابتة 0.28–0.5 | `GameScreen:203-230` قيم حرفية بلا `fxIntensity` |
| W9 | ملخص الجولة لا يعرض أعلى كومبو ولا عدد التتريس رغم توفرهما في المحرك | `GameEngine.maxCombo/tetrises` موجودان، `UiState` لا يمرر `maxCombo` |

## 2) المسار A — الصوت (البنود A1–A7)

| البند | الوصف | بوابة التحقق |
|---|---|---|
| **A1 — تركيز الصوت** | `AudioFocusHelper` (USAGE_GAME) يطلب التركيز عند بدء الجولة ويتخلى عنه عند انتهائها؛ `FocusPolicy` (نقي قابل للاختبار): فقد دائم ⇒ إيقاف الجولة تلقائياً، فقد مؤقت ⇒ إيقاف الموسيقى، استعادة ⇒ استئناف الموسيقى | اختبارات `FocusPolicy` الأربع + بناء |
| **A2 — سلّم نغمة الكومبو** | `ComboPitch` نقي: combo≥2 يُشغّل صوت COMBO بمعدل 1.00→1.50 (خطوة 0.05، سقف 1.5)؛ `SfxEngine.play` يكتسب معامل `rate` (SoundPool.setRate) | اختبارات: null دون 2، رتيب تصاعدي، سقف، أساس عند 2 |
| **A3 — موسيقى الخطر الديناميكية** | `MusicRouter` نقي يوحد القرار: zen ⇒ ZEN، خطر نشط ⇒ PLAY_INTENSE، مستوى ≥8 ⇒ PLAY_INTENSE، وإلا PLAY؛ يُستدعى عند تغيّر حالة الخطر فقط (بلا تذبذب) | اختبارات المسار الأربعة + لا تبديل عند ثبات الحالة |
| **A4 — خفوت الموسيقى تحت المعلق** | `DuckPolicy` نقي (مدة 1100ms، معامل 0.45)؛ `MusicEngine.duckFor()` يخفض الحجم مؤقتاً عند كل حدث معلق مقاطِع (تتريس/مثالية/رقم قياسي/نهاية) | اختبارات السياسة + كود التوصيل |
| **A5 — صوتا PERFECT وB2B** | حدثان جديدان في `SfxEngine.Sound` + 8 ملفات WAV مولّدة (4 حزم × 2) بنفس أسلوب v2 (طبقة تحتية + سويب صاعد)؛ سلسلة احتياط: PERFECT→TETRIS→CLEAR، B2B→COMBO→CLEAR | `SfxSoundMapTest` موسّع + الملفات داخل APK |
| **A6 — صمت الخلفية الكامل** | `GameViewModel.onAppBackgrounded()`: إيقاف الجولة + حفظ الجلسة + إيقاف الموسيقى **وإسكات المعلق فوراً** (بلا عبارة PAUSE) | كود + مراجعة مسار ON_PAUSE |
| **A7 — معاينة صوت الحزم في المتجر** | `SfxEngine.playFrom(pack, sound)` يشغّل من حزمة اعتباطية دون تبديل النشطة؛ زر «معاينة» في بطاقة كل حزمة يشغّل CLEAR ثم TETRIS منها | كود + بناء؛ زر يظهر في فئة الأصوات فقط |
