## 1) الهدف من الإصدار

أربع فجوات لاعب-حقيقية ظهرت من مراجعة الكود والتقارير السابقة، يغلقها هذا الإصدار:

1. **العدالة التنافسية:** المحرك يكتشف T-Spin كنوع واحد فقط، فحركات «ميني» الماهرة تساوي الحركات الكاملة رغم اختلاف صعوبتها — يُضاف تمييز Mini T-Spin بنقاط مستقلة.
2. **الشفافية اللحظية:** شريط الأحداث يعرض تتريس/سبين/كومبو لكنه لا يعرض Back-to-Back أصلاً (النوع موجود بالكود ولم يُستخدم — خلل اكتمال) ولا يميز الميني.
3. **سهولة الوصول:** الاعتماد الحصري على اللمس/السحب يستثني من يفضل الأزرار — تُضاف أزرار على الشاشة اختيارية مع بقاء الإيماءات الافتراضية.
4. **الانطلاقة الأولى:** لاعب جديد يواجه 11 نمطاً بلا شرح — تُضاف شاشة «كيف تلعب» تظهر مرة واحدة + زر دائم، وزر مشاركة نتيجة الجولة.

## 3) ما لن يُنفَّذ في v1.1.0 (بشفافية)

- **الوضع الأفقي:** يتطلب إعادة تصميم تخطيط كامل؛ يُؤجل لإصدار رئيسي لاحق بقراره الخاص.
- **تمييز Mini المُرقّى بركلة TST:** يتطلب تتبّع فهرس الركلة الأخيرة في المحرك؛ القاعدة الزاويّة الصرفة تكفي لهذا الإصدار (موثق كحد معروف).
- **تكرار تلقائي بالاستمرار على الأزرار:** الأزرار تنفذ نقرة = فعل واحد؛ التكرار التلقائي (DAS) للإيماءات يبقى كما هو.
- **لقطات شاشة في README:** لا بيئة جهاز/محاكي — تبقى قيداً معروفاً معلناً.

```
A1 → A2 → A3 → [تشغيل اختبارات المحرك] → B1 → B2 → B3 → B4 → C1 → C2
→ [D1 اختبارات جديدة] → [D2 إثبات كامل] → D3 → D4 → D5
```
