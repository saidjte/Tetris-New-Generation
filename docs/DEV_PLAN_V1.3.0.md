# خطة عمل تفصيلية — v1.3.0 «العرض والصوت»
## Presentation & Audio Plan — Tetris New Generation

<div dir="rtl">

**التاريخ:** 26 أكتوبر 2026 · **الحالة الحالية:** v1.2.0 (versionCode 4) · **الهدف:** جعل اللعبة أجمل وأقوى وأكثر تشويقاً، مع تركيز على المؤثرات الصوتية والبصرية.

## 0) منهجية الخطة

1. **مصدر البنود = ملفات المشروع نفسها.** تدقيق كود فعلي بتاريخ 26/10/2026 كشف ما يلي من مميزات موجودة على الورق (في الكتالوج والمستندات) لكنها **غير مفعّلة فعلياً** أو بدائية التنفيذ — فالخطة تُحييها بدل اختراع مميزات جديدة من الصفر.
2. **سياسة الإصدار ملزمة:** كل بنود هذه الخطة تصدر ضمن **v1.3.0 (versionCode 5)** — إصدار ثانوي لأنها تضيف قدرات جديدة (أصوات جديدة + مؤثرات بصرية جديدة)، وفق جدول CHANGELOG.
3. **بوابات تحقق لكل بند** (اختبار/بناء/فحص APK) و**حدود صدق** معلنة في نهاية المستند.
4. احترام دائم: «تقليل الحركة» يعطّل كل الاهتزاز البصري، و«تعطيل الاهتزاز اللمسي» يعطّل كل الطقطقة اللمسية.

## 2) بنود العمل — المسار A: الصوت (gen_audio.py v2 + التوصيل)

| البند | الوصف | بوابة التحقق |
|---|---|---|
| **A1 — تخليق أغنى** | إعادة توليد كل أصوات الحزم الأربع بتقنيات أعمق: طبقة Sub تحت النغمة الأساسية + Detune خفيف (ثريّة) + Sweep صاعد للنجاحات + Noise Transient للطقطقات + مغلف ADSR أطول إطلاقاً — مع الحفاظ على «شخصية» كل حزمة (أصلي ناعم، أركيد حاد، مستقبلي FM، هادئ ثلاثي) | إعادة التوليد بدون أخطاء؛ كل الملفات WAV سليمة 22050Hz |
| **A2 — حدثان جديدان × 4 حزم** | `countdown` (بيب قصير A5) و`go` (نغمة انطلاق C6 مع أوكتاف) → **63 أصلاً صوتياً** (4×15 + 3 موسيقى) | `SfxEngine.Sound` يضيف `COUNTDOWN, GO`؛ الملفات داخل APK |
| **A3 — عد تنازلي 3-2-1-انطلق!** | طبقة واجهة قبل بدء أي جولة جديدة (تُتخطى عند استئناف جلسة محفوظة): 3 نبضات × 550ms ثم «انطلق!» 650ms، كل نبضة بصوتها واهتزازها | الكود + تجربة بناء؛ الاستئناف يبدأ فوراً |
| **A4 — تحذير الوقت** | في الأنماط الموقوتة: عند بلوغ آخر 10 ثوانٍ يُطلق صوت بيب واحد لمرة واحدة لكل جولة | علم `timeWarned` يُصفَّر عند `start()`؛ لا تكرار |

## 3) بنود العمل — المسار B: المحرك (أدنى تغيير ممكن)

| البند | الوصف | بوابة التحقق |
|---|---|---|
| **B1 — صفوف الإزالة في الحدث** | `GameEvent.LinesCleared` يكتسب `clearedRows: List<Int> = emptyList()` (قيمة افتراضية = توافق كامل مع الاختبارات القديمة) ويُملأ من `board.clearFullRows()` | اختبار جديد: لوحة مرسومة يدوياً + قطعة I ثابتة → الحدث يحمل رقم الصف الصحيح |

## 4) بنود العمل — المسار C: المؤثرات البصرية (قلب الإصدار)

| البند | الوصف | بوابة التحقق |
|---|---|---|
| **C1 — توصيل الحزم الخمس فعلياً** | `Particle` يكتسب `style`؛ `spawnBurst` يستخدم نمط وكثافة الحزمة المشتراة من `PackDefs.effectPack(ui.effectPackId)`؛ `BoardCanvas` يرسم كل نمط كما يلي: **SPARKS** خِط طويلة متطايرة، **BURST** دوائر (الوضع الحالي)، **TRAIL** خطوط ممدودة باتجاه السرعة، **SHATTER** مربعات دوّارة، **CONFETTI** مستطيلات رفيعة ترفرف بدوران | الكود؛ الشكل يتغير مع الحزمة المختارة في المتجر |
| **C2 — وميض الصفوف المزالة** | شريط أبيض-ساخن يمسح كل صف مزال ويتلاشى خلال ~260ms (عرض ممسوح بمنحنى ease-out) — يعتمد B1 | الكود + `FxMath.beamWidth` مُختبر |
| **C3 — نقاط طائرة** | «+N» تكبر وترتفع وتتلاشى (~700ms) عند كل إزالة، بقيمة `points` الفعلية من الحدث | الكود + `FxMath.popupRise/popupAlpha` مُختبران |
| **C4 — اهتزاز الشاشة** | اهتزاز مخمّد: هبوط صلب 4px/200ms، سبين 6px، تتريس 8px/320ms، تصفية مثالية 10px — `FxMath.shakeOffset` جيبية مخمدة تضمن العودة إلى الصفر | مُختبر: العودة للصفر عند البداية والنهاية والحد الأقصى داخل المدى |
| **C5 — حلقة صدمة** | حلقة دائرية تتوسع من مركز اللوحة عند التتريس/المثالية (نصف قطر ease-out + شفافية متناقصة) | `FxMath.ringRadius/ringAlpha` مُختبران |
| **C6 — توهج الكومبو** | إطار اللوحة يتوهج برتقالياً ويزيد سماكته تدريجياً مع سلسلة الكومبو (حرارة = min(combo/5, 1)) | `FxMath.comboHeat` مُختبر |
| **C7 — نبض الشبح** | شفافية القطعة الشبحية تتنفس 0.14↔0.34 بدورة ~950ms (ثابتة عند تقليل الحركة) | `FxMath.ghostAlpha` مُختبر بالحدود |
| **C8 — طبقة العد التنازلي** | أرقام 3·2·1 تتقلص للداخل ثم «انطلق!» تتقلص للخارج فوق اللوحة (تُتخطى عند الاستئناف) | الكود؛ تسلسل النبضات في `CountdownSteps` مُختبر |

**الرياضيات كلها في كائن نقي واحد `FxMath` + `CountdownSteps`** — قابلة للاختبار على JVM بلا أندرويد، ويبقى الرسم مستهلكاً لها.

## 6) ما **لن** يُنفذ في هذا الإصدار (صدق كامل)

- **موسيقى ديناميكية متعددة الطبقات** (تشتد مع المستوى) — تتطلب محرك خلط أعمق؛ مؤجلة إلى v1.4.0.
- **إعداد «شدة المؤثرات» في الإعدادات** — خارطة v1.4.0 (تصحيح لادعاء PLAN.md §5).
- **ثيمات جديدة / حزم أصوات جديدة** — المتجر الحالي يبقى كما هو؛ هذا الإصدار يجعل ما بِعتَه **مرئياً أخيراً**.
- **اهتزاز الجهاز الكامل (Vibration API)** — نستخدم `HapticFeedback` القياسي فقط كما في v1.2.0.

## 7) ترتيب التنفيذ (تسلسل الاعتماد)

```
B1 (حدث الصفوف) → D1 جزء المحرك
A1 → A2 (توليد + SfxEngine)
FxMath + CountdownSteps → D1 جزء الرياضيات
C1..C8 (تعتمد على B1 + FxMath + A2)
A3, A4 (تعتمد على A2)
D2 → D3 (توثيق ثم إصدار)
```
